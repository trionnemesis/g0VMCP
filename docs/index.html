g0VMCP

用一句話，問出台灣政府採購標案情報。
衛福部資訊服務類標案 × Model Context Protocol。

GitHub → 快速開始 回報問題

💬 裝好之後，直接這樣問 Claude

「衛福部最近三個月有哪些預算 500 萬以上、還在招標中的資訊服務案？」

→ search_tenders 依機關、狀態、預算、日期多維篩選，回傳標案摘要清單

「這個標案從公告到決標經過哪些更正？底價和決標金額差多少？」

→ get_tender_lifecycle + get_tender_detail 還原完整事件時間線與加值欄位

「統編 12345678 這家廠商過去拿過哪些衛福部的案子？」

→ get_vendor_awards 以統編反查歷史得標紀錄

✨ 為什麼需要 g0VMCP？

🧩 補完缺漏欄位

公開資料集沒有的預算金額、底價、投標家數、開標時間，自動從明細頁抓取補完。

🔄 完整生命週期

招標 → 更正 → 決標的分散公告，聚合成單一標案的完整事件時間線。

🤖 AI 原生介面

透過 MCP 協定，Claude 或任何相容 Agent 都能直接用自然語言查詢。

🛠 自動化同步

CLI 半月增量抓取、Cloudflare 擋牆自動退避，SQLite 本地儲存零依賴。

🚀 三步驟開始

1
安裝（Python 3.11+） 
pip install git+https://github.com/trionnemesis/g0VMCP.git
2
加入 Claude Code 
claude mcp add g0vmcp -- g0vmcp
3
同步資料 
g0vmcp-sync && g0vmcp-enrich
